### How good the name matcher is

Tested on the 53 names first seen on the July 2026 sheet, with the 50 rows the group added for them
(vocabulary Pass 6) taken out:

| Suggestion | Names | Agrees with the group's choice |
|---|---:|---:|
| Strong | 40 | 39 (the 40th is a pair already on the merge-candidate list) |
| Weak | 12 | 9 |
| None | 1 | 1 (a genuinely new item) |

A person confirms every suggestion; nothing is written on its own. The earlier rough test (46 matched,
42 correct) matched more names but made more mistakes.

### What staff do now (Tally Interface)

- **Names to review** (top of the page, hidden when empty): for each name, *Yes, same item*,
  *A different item…*, or *It is a new item*. A sheet name takes effect at the next pipeline run, and
  the staleness banner counts it until then.
- **Rename Item** (Monthly Inventory Count card): when the sheet starts calling an item something else.
  The item keeps its history and the name shown on the dashboard.
- **Add Tally Workbook** (Full Pipeline Run card): add the store's workbook, then run the pipeline.
